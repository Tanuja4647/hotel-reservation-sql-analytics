# 🏨 Hotel Reservation Operations Analytics

## 📌 Project Overview

This project analyzes hotel reservation data using SQL and MySQL to identify booking trends, hotel performance, customer behavior, room-type demand, and revenue-related insights.

## 🛠️ Tools & Technologies

* MySQL
* MySQL Workbench
* SQL

## 📊 Key Analysis

The project includes analysis of:

* Booking trends
* Hotel performance
* Booking channel performance
* Room-type demand
* Cancellation patterns
* Customer behavior
* Revenue and booking value
* Monthly and yearly booking trends

## 🎯 Objective

The objective of this project is to use SQL to transform hotel reservation data into meaningful business insights that can support better decision-making in hotel operations.
